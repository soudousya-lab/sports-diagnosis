# NOBISHIRO ATHLETE - アスリート向け運動能力診断システム

## プロジェクト概要

NOBISHIRO ATHLETEは、**中高生〜大人向けの運動能力診断システム**です。NOBISHIRO KIDSの上位版として、より本格的なフィジカルテストを実施し、アスリートのパフォーマンス向上をサポートします。

### ターゲットユーザー
- **部活動・クラブチーム**: 選手のフィジカル状態を定期的に測定・管理
- **パーソナルジム・フィットネス**: 会員の体力測定とトレーニング処方
- **スポーツ施設・トレーニングセンター**: アスリート向け総合診断サービス
- **企業・団体**: 従業員の健康管理・体力測定

## 想定する測定項目

### 基本フィジカルテスト（10項目）

| 項目 | 測定内容 | 評価観点 |
|------|---------|---------|
| 握力 | 左右の最大値(kg) | 絶対筋力 |
| 背筋力 | デッドリフト姿勢での引き上げ力(kg) | 体幹・下肢筋力 |
| 垂直跳び | 跳躍高(cm) | 下肢パワー |
| 立ち幅跳び | 跳躍距離(cm) | 水平方向の瞬発力 |
| 30m走 | 走行タイム(秒) | スプリント能力 |
| プロアジリティ | 5-10-5走のタイム(秒) | 方向転換能力 |
| 反復横跳び | 20秒間の回数 | 敏捷性 |
| 長座体前屈 | 前屈距離(cm) | 柔軟性 |
| 上体起こし | 30秒間の回数 | 腹筋持久力 |
| 20mシャトルラン | 往復回数 | 有酸素持久力 |

### 競技別オプションテスト

| 競技 | 追加テスト |
|------|----------|
| サッカー | 5mダッシュ、T字テスト、キック力測定 |
| 野球 | 塁間走、投球速度、スイングスピード |
| バスケ | レーンアジリティ、リーチ高、シュート精度 |
| バレー | ブロックジャンプ、スパイク到達点 |
| 陸上 | スタート反応、10m通過タイム、後半失速率 |

## 予定機能

### 1. 診断機能
- **総合評価レーダーチャート**: 10項目のバランス表示
- **競技適性診断**: 測定結果から適性競技・ポジションを提案
- **偏差値・パーセンタイル表示**: 同年代・同競技との比較
- **成長グラフ**: 過去データとの比較、トレンド分析

### 2. トレーニング処方
- **個別メニュー生成**: 弱点・目標に応じたプログラム
- **負荷設定**: 年齢・経験に応じた適切な強度
- **期分け（ピリオダイゼーション）**: オフ→準備期→試合期の設計
- **リカバリー指導**: 疲労度に応じた休養提案

### 3. チーム管理機能
- **選手一覧管理**: チーム全体のフィジカルデータ一覧
- **ポジション別比較**: 同ポジション選手の比較分析
- **コンディション管理**: 疲労度・体重・睡眠の記録
- **出力機能**: チームレポート・個人レポートのPDF出力

### 4. ベンチマーク機能
- **プロ基準との比較**: Jリーガー、プロ野球選手などの参考値
- **大学・高校強豪校データ**: 競技レベル別の目標設定
- **日本代表基準**: 各競技の代表クラスの数値

## 競合サービスとの差別化

### 既存サービスの課題
- 高価格帯のプロ向けシステムが多い
- 導入・運用が複雑
- 日本の競技環境に最適化されていない
- 子ども→大人への継続性がない

### NOBISHIRO ATHLETEの強み
- **NOBISHIRO KIDSとのシームレスな連携**: 小学生時代のデータを引き継ぎ
- **日本の競技基準**: 日本の部活・クラブ環境に最適化
- **シンプルな操作性**: スマホで簡単に入力・閲覧
- **適切な価格帯**: 部活顧問・コーチでも導入しやすい価格
